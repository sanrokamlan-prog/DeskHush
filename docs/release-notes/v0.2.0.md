# DeskHush v0.2.0

本版本补齐了短暂弹窗和难以手动选中窗口的识别流程。

## 新增功能

- “桌面抓取”会冻结当前虚拟桌面，自动标出可识别的顶层窗口；点击目标即可带入弹窗规则编辑器；
- “窗口记录”可在后台收集新出现窗口的进程、标题、窗口类、位置和尺寸，并从记录直接创建规则；
- 记录按最新优先显示，自动去重并限制为最多 500 条，也可随时手动清空；
- 后台记录使用有界队列和固定消费者，短时间大量窗口不会无限占用线程池；清空后旧任务不会重新写回；
- 增加每天一次、可关闭的新版本检查；发现新版后在设置页和托盘提示，点击后才打开 Release 页面；
- EXE、主窗口和托盘统一使用包含 16 至 256 像素尺寸的新图标；
- 现有的进程限定、窗口特征校验和系统关键进程保护继续适用于所有新建规则。

## 隐私边界

- 桌面画面只在内存中用于当前选择器，不生成截图文件，关闭选择器后释放；
- 窗口记录只保存在当前 DeskHush 进程内存中，退出后清除；
- 截图和窗口记录均不会上传。
- 版本检查只读取公开 Release 元数据，不携带 GitHub 凭据、规则或窗口数据，可在设置页关闭。

## 使用建议

1. 对停留时间足够长的窗口，继续从“当前窗口”列表创建规则。
2. 对已显示但列表中难以辨认的窗口，使用“桌面抓取”直接点击目标。
3. 对出现后很快消失的窗口，先开启“窗口记录”，复现弹窗后从历史记录创建规则。
4. 新建规则默认使用“隐藏”；标题尚未生成的记录会创建暂停规则，确认匹配条件后再启用。

当前发行包面向 Windows 10/11 x64，由 GitHub Actions 生成自包含单文件 ZIP 和 SHA-256 校验文件。完整操作与恢复说明见 [README](../../README.md) 和 [Safety and Recovery](../safety-and-recovery.md)。
