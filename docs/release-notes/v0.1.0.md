# DeskHush v0.1.0

首个公开版本，提供一个轻量的 Windows 桌面管理器。

## 主要功能

- 基于进程、窗口类与标题规则的弹窗关闭/隐藏；
- 可恢复的资源管理器静态右键菜单与 shell extension 管理；
- 可恢复的 `Run`、`RunOnce` 与启动文件夹管理，并识别任务管理器启动批准状态；
- 托盘后台运行、单实例和当前用户开机启动；
- 普通权限默认运行，需要修改本机范围项目时显式提权；
- 自包含 Windows x64 单文件发行包和 SHA-256 校验文件。

## 使用前须知

- 当前发行包未进行代码签名，Windows SmartScreen 可能显示未知发布者；
- 启动项管理暂不包含计划任务、Windows 服务或驱动；
- 新弹窗规则建议先使用“隐藏”动作验证，避免误关包含未保存内容的窗口；
- 禁用右键菜单或启动项后，不要在恢复前删除 `%LOCALAPPDATA%\DeskHush`；

完整操作与恢复说明见 [README](../../README.md) 和 [Safety and Recovery](../safety-and-recovery.md)。
